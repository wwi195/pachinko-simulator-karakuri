# カラサー2 シミュレーター 仕様

作成日：2026-11-24。スペックはDiscordでユーザーと確認して決めた。画面の形は `pachinko-simulator-ring` と同じ。
数字は実機のスペック（公開情報：なな徹・1geki・psumma のスマパチ版）を元にし、一劇の中の仕組みはユーザーの説明から作った。まだ仮のデータ。

## 遊技条件
- 等価（4円/玉）固定。回転数/千円は 12／14／16.4（ボーダー・初期値）／18／20。ボーダー16.4はなな徹の等価ボーダー（表記出玉・持ち玉比率65%）。
- 実際の獲得球：表示×14/15（1200→1120、1500→1400、300→280）。

## 通常時
- 図柄揃い 1/399.9 ＋ からくりチャージ 1/396（300個・通常へ）＝ 合算 約1/199。
- 先告知などの演出はまだ入れない（出し方は後で決める）。
- 図柄揃いの振り分け：1200個＋LT 51%／300個＋LT 1%／1200個で通常へ 48%（LT突入 52%）。初当たり全体からは約26%。

## LT（ST135回）
- 1回転ごとに 1/78 で「一劇」。
- 一劇は保留5個。全部外れ（V0）が 17.52% になるように、保留1個の当たりは 約1/3.40。
- 当たった数 × 1500個（1個 1500／2個 3000／3個 4500／4個 6000／5個 7500）。当たればSTは135回に戻る。
- V0 のときは半々（8.76%ずつ）で「STリセット（135回から・出玉なし）」か「ST残りから再開」。
- 大当たり（ボーナス＋リセット）の割合：1500 40.0%／3000 33.4%／4500 13.9%／6000 2.9%／7500 0.24%／リセット 9.6%（公開値 40／33／17／10 とほぼ同じ）。継続率 約80%（リセット込み）。

## 画面
- 一劇は保留5個を PUSH で1個ずつ開ける（「全部開ける」もある）。
- ボーナスは「1500ボーナス！」＋小さく（実質獲得）。からくりチャージは「チャージ！」。3000以上は「10R×◯」。
- LTは 1回転／10回転／スキップ（一劇か残り10回まで）。
